# Происхождение набора

`labels.csv` — производная работа от набора **Nutrition5k**.

- Авторы: Quin Thames, Arjun Karpur, Wade Norris, Fangting Xia, Liviu Panait,
  Tobias Weyand, Jack Sim (Google Research, CVPR 2021).
- Репозиторий: https://github.com/google-research-datasets/Nutrition5k
- Статья: https://arxiv.org/abs/2103.03375
- Лицензия данных: **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/

## Что откуда взято

Массы порций и питательные значения в `labels.csv` — исходные аннотации
Nutrition5k. Русские названия блюд, деление на простые и составные, метки типов
(скрытые калории, маленькие и большие порции) и сама выборка пятидесяти
записей — производные материалы подборки, собранной для этого проекта.

Фотографии в репозиторий не включены: они лежат в `photos/`, который не
версионируется. Исходные PNG преобразованы в JPEG с качеством 95 без изменения
размеров и кадрирования.

## Что это значит для выводов

Nutrition5k использует массы ингредиентов и справочные таблицы, а не химический
анализ каждой готовой тарелки. Это хороший эталон для сравнения моделей между
собой, но не абсолютная истина о калорийности.

Набор лежит в открытом доступе с 2021 года, поэтому сравниваемые модели могли
видеть его при обучении. Часть точности на этом наборе может оказаться памятью,
а не зрением. Вывод «модель X точнее» справедлив для этого набора; для бота его
нужно подтверждать на отложенных снимках, сделанных телефоном в обычных
условиях.

При распространении производных материалов сохраняйте эту атрибуцию.
