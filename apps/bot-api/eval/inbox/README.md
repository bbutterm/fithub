# Папка для своих фотографий

Положите сюда снимки еды, запуште — и GitHub Actions прогонит их через
несколько моделей и пришлёт отчёт комментарием к коммиту.

```
apps/bot-api/eval/inbox/
  обед.jpg
  ужин.jpg
  labels.csv        ← необязательно
```

Подойдут `.jpg`, `.png`, `.webp`. Уменьшать заранее не нужно: прогон сам
ужимает снимки до размера из `eval/config.json` и кладёт уменьшённые копии в
папку прогона, оригиналы остаются как есть.

## С весами и без

**Без `labels.csv`** считать точность не из чего, поэтому отчёт показывает
согласие: насколько каждая модель отклоняется от того, что сказали остальные,
кто систематически завышает, а кто занижает, и на каких снимках модели
разошлись сильнее всего.

Согласие — это не точность. На плотной еде со скрытым жиром занижает весь
набор сразу, и общее мнение тогда так же неверно, как каждый ответ. Отчёт
отвечает, кто выбивается из общего мнения, а не кто прав.

**С `labels.csv`** считается настоящая ошибка. Формат тот же, что у основного
набора:

```csv
file,dish,grams,kcal,protein,fat,carbs,source,tags,holdout
обед.jpg,"Гречка, Куриная грудка",320,480,42,9,58,кухонные весы,mixed,no
```

Вес — с кухонных весов, КБЖУ — с упаковки или из справочника. Метки
необязательны: `simple`, `mixed`, `hidden`, `small`, `large`, `lowlight`,
`multi`.

## Сколько это стоит

Вызовов получается «фотографий × моделей × повторов». По умолчанию гоняются
пять моделей из `inboxModels` в `eval/config.json`, один повтор: десять снимков
обойдутся примерно в двадцать центов. Прогон не начнётся, если вызовов выходит
больше ста двадцати — предел меняется входом `max_calls` при ручном запуске.

В списке три модели Google, и это не для полноты: на эталонном наборе они
оказались неразличимы между собой, так что разойтись могут только на живых
снимках. Рядом дешёвый вариант и та модель, что стоит в боте сейчас, — чтобы
было с чем сравнивать.

## Запуск руками

Из вкладки Actions → «Eval по своим фото» → Run workflow. Там же меняются
модели, число повторов и папка. Локально то же самое:

```
pnpm --filter bot-api eval inbox
pnpm --filter bot-api eval inbox --dir inbox --models google/gemini-3.6-flash,deepseek/deepseek-v4.1-flash --runs 2
```

Нужен ключ: `VISION_API_KEY` в окружении или в `apps/bot-api/.env`. Для
Actions — секрет репозитория `OPENROUTER_API_KEY`.

## Что держать в голове

Десять снимков не ранжируют модели. Интервал неопределённости на таком
количестве шире любой разницы в таблице — на пятидесяти студийных снимках не
разошлась ни одна пара моделей. Эта папка отвечает на другой вопрос: что
происходит **на ваших** фотографиях, снятых телефоном при обычном свете, и
насколько это расходится с замером на эталонном наборе.

Снимки отсюда попадают в репозиторий вместе с коммитом. Не кладите то, что не
готовы хранить в истории.
